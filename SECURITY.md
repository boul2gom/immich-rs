# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| `0.2.x` | :white_check_mark: |
| `< 0.2.0` | :x: |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, please report them privately via:
- [GitHub Private Vulnerability Reporting](https://github.com/boul2gom/immich-rs/security/advisories/new), or
- Email to **contact@boul2gom.fr**.

Please include a clear description of the issue, affected versions/features, and minimal reproduction steps. You can expect an initial acknowledgment within 72 hours.
